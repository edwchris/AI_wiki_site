# qmd

Quarto Markdown — the document format used by Quarto, a scientific publishing system. Extends Markdown with executable code chunks (R, Python, Julia), cross-references, and rich output formats (HTML, PDF, slides, books).

## Relevance to this wiki
- Mentioned in CLAUDE.md as a potential navigation/publishing tool at scale (beyond 100 sources)
- Could serve as an alternative to index.md for large-scale wiki navigation: generate a searchable website from wiki content
- Useful for converting wiki analyses into publishable reports
