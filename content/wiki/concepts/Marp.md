# Marp

A Markdown-to-presentation framework with an [[Obsidian]] plugin variant. Allows wiki content to be converted into slide decks using YAML directives and Markdown layout syntax, without leaving the Obsidian environment.

## Use in this wiki
- Enables wiki content to be repurposed as presentations for teaching or conference talks
- Part of the knowledge reuse layer in the [[LLM Wiki Pattern]]

## Connections
- [[Obsidian]] — environment where the Marp plugin runs
