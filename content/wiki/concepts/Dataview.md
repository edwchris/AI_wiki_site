# Dataview

An [[Obsidian]] plugin that treats the vault as a database, enabling SQL-like queries over YAML frontmatter and inline fields. Allows dynamic tables and lists to be generated from page metadata (e.g., "show all pages with type: concept, sorted by created date").

## Use in this wiki
- Can generate dynamic indices of pages by type, tag, or date
- Complements the manually maintained [[LLM Wiki Pattern]] index with automatic cross-section views
- Not required for core wiki function but useful for navigation at scale

## Connections
- [[Obsidian]] — the environment this plugin extends
- [[LLM Wiki Pattern]] — the wiki pattern that benefits from Dataview for large-scale navigation
