# micrograd

A minimalist autograd engine built by [[Andrej Karpathy]] for educational purposes. ~100 lines of Python. Implements scalar-valued backpropagation and a small neural network library on top, demonstrating that the core of modern deep learning frameworks (PyTorch, TensorFlow) is conceptually simple.
