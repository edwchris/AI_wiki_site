**Citation:** Nicholls, D., Sweet, L., & Hyett, J. (2014). Psychomotor skills in medical ultrasound imaging: An analysis of the core skill set. *Journal of Ultrasound in Medicine*, 33(8), 1349–1352. DOI: 10.7863/ultra.33.8.1349

**Raw file:** `Nicholls, Sweet, Hyett - 2014 - Psychomotor Sk.pdf` (also: `Nicholls, Sweet, Hyett - 2014 - Psychomotor S1.pdf` and `J of Ultrasound Medicine - 2014 - Nicholls - P.pdf` — likely same paper, multiple downloads)

## Summary
Identifies and analyses the core psychomotor skill set required for medical ultrasound imaging. Defines psychomotor skills as voluntary movements regulated by the motor cortex in response to sensory stimuli. Provides a foundation for understanding why ultrasound is not purely a cognitive task — physical skill is central — and why AI automation of the physical component raises distinct educational concerns.

## Core Psychomotor Skills in Ultrasound

| Skill Component | Description |
|-----------------|-------------|
| Probe manipulation | Translating, rotating, tilting, compressing to obtain target views |
| Hand-eye coordination | Correlating probe movement with on-screen image response in real time |
| Bilateral coordination | Controlling probe (one hand) while operating machine controls (other hand) |
| Pressure calibration | Adjusting probe pressure for patient comfort, image quality, and tissue compression |
| Spatial orientation | Maintaining 3D mental model of anatomy during 2D real-time imaging |

## Key Arguments
- Psychomotor skill in ultrasound is a distinct dimension from cognitive image interpretation
- Skill is acquired through repeated, feedback-rich practice — classic deliberate practice model
- Skill cannot be learned vicariously (watching) or didactically (reading); physical repetition is required
- Assessment of psychomotor skill requires direct observation, not written tests

## Implications for AI
- AI real-time guidance tools (probe navigation assistants, plane detection overlays) automate the feedback loop that develops psychomotor skill
- Novices using AI guidance may achieve diagnostic images without developing the hand-eye coordination to do so independently
- This is a form of [[Ironies of Automation]] at the psychomotor level: AI assists acquisition → skill never develops → AI dependency
- Connects directly to [[Deliberate Practice in Sonography — Edwards et al. 2018]] and [[AI Education in Medical Imaging]]
- See also [[AI-Enhanced Cardiac US Training — Karni et al. 2025]] for empirical evidence of this effect
